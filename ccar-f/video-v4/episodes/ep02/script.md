## SLIDE: 第1章　最小のエージェントループ
@code_label: Python SDK の最小形
@diagram: flow | 1周の中身
@node: 履歴ごとAPIを呼ぶ
@node: 応答を履歴に追加
@node: tool_use なら全て実行
@node: 結果を1メッセージで返す
```text
while True:
  resp = client.messages
    .create(messages=messages)
  messages.append(assistant)
  if resp.stop_reason
       != "tool_use":
    break
  results = run_all(resp)
  messages.append(user: results)
```
[L] ずんだもん: コードで見ると、こうなるのだ。応答が来たら、まずアシスタントの内容を、必ず履歴に追加するのだ。
[L] めたん: {stop_reason|ストップリーズン}が{tool_use|ツールユース}でなければ、ループを抜けますのね。
[R] ずんだもん: 右の流れ図が、1周の中身なのだ。
[R] ずんだもん: {tool_use|ツールユース}なら、ブロックを全部実行して、結果を1つのユーザーメッセージで返すのだ。
[R] めたん: {max_tokens|マックストークンズ}の打ち切りなどは、別に扱うのですわね。
