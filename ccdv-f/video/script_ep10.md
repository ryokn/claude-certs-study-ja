## SLIDE: 公式サンプル問題の要点
| # | 分野 | 正解の考え方 | 不正解の典型 |
| 1 | 分野2 | 夜間の非緊急な1万件 → Message Batches API（24時間以内・低コスト） | 同期の並列送信、max_tokens を下げる、むやみに最小モデルにする |
| 2 | 分野7 | Web ページの隠し指示 → 信頼できない入力として分離し、ガードレールやフックで機密性の高いアクションを防ぐ | temperature、お願いの一文、大きなモデル |
| 3 | 分野8 | 社内の REST API を複数アプリで再利用 → MCP サーバー | プロンプトにハードコード、データの貼り付け、組み込みツール |

めたん: 1問目は、第1回で出てきましたわね。
ずんだもん: 夜間の、急がない1万件の処理なのだ。正解は{Message Batches API|メッセージ バッチズ エーピーアイ}。24時間以内で、50パーセント割引なのだ。
めたん: 不正解の典型は？
ずんだもん: 同期の並列送信、{max_tokens|マックストークンズ}を下げる、むやみに最小モデルにする、なのだ。
めたん: 並列にしても、単価は変わらないのでしたわね。
ずんだもん: そうなのだ。それに、モデルを切り替えるなら、{eval|イーバル}を回し直す必要があったのだ。
めたん: 2問目は、第8回のインジェクションですわね。
ずんだもん: ウェブページの隠し指示なのだ。信頼できない入力として分離して、ガードレールやフックで、機密性の高いアクションを防ぐのだ。
めたん: 不正解は、{temperature|テンパラチャー}、お願いの一文、大きなモデル。
ずんだもん: 完璧なのだ。3問目は、第7回の{MCP|エムシーピー}なのだ。
めたん: 社内の{REST API|レスト エーピーアイ}を、複数のアプリで再利用したい。答えは{MCP|エムシーピー}サーバーですわ。
ずんだもん: 正解なのだ！不正解は、プロンプトにハードコード、データの貼り付け、組み込みツールなのだ。

## SLIDE: 3問に共通する「解き方の型」★
- **強制力のある仕組み** を選ぶ：**API の機能、フック、権限、MCP**
- **「お願い・ランダム性・モデルの大きさ」** に頼る選択肢を外す
- 消去法（直前チェックリストより）：
- 「お願い」「temperature」「とりあえず大きなモデル」「無限リトライ」「全部をコンテキストに貼る」は **たいてい誤り**

めたん: 3問を並べると、何か見えてきますわね。
ずんだもん: そうなのだ。共通する型があるのだ。強制力のある仕組みを選ぶのだ。{API|エーピーアイ}の機能、フック、権限、{MCP|エムシーピー}なのだ。
めたん: 逆に、外す選択肢は？
ずんだもん: お願い、ランダム性、モデルの大きさに頼る選択肢なのだ。
めたん: バッチは{API|エーピーアイ}の機能、インジェクションはフック、社内{API|エーピーアイ}は{MCP|エムシーピー}。確かに全部、仕組みで解決していますわ。
ずんだもん: 消去法も覚えておくのだ。お願い、{temperature|テンパラチャー}、とりあえず大きなモデル、無限リトライ、全部をコンテキストに貼る。これは、たいてい誤りなのだ。
めたん: 迷ったら、まずそれを消す、ですわね。

## SLIDE: 演習のコツと、使ってはいけないもの
- 同じ問題を何周もするより、**初めて見る問題で9割を安定して取れるか** を指標にする
- 間違えた問題は **公式ドキュメントで裏付け** を取り、本ガイドの該当分野を読み直す
- 外部の問題集は **非公式** → 解説の誤りや古い仕様に注意（本ガイドの「要確認」項目も参照）
- 実際の試験問題を流出させた **「dump」系サイト**（例：ITExamsPro.com）は **受験規約違反**
- → **合格取り消しや受験禁止のリスク** があるため使わない

めたん: 演習のコツは、ありますの？
ずんだもん: 同じ問題を何周もするより、初めて見る問題で、9割を安定して取れるかを指標にするのだ。
めたん: 答えを覚えてしまっては、意味がありませんものね。
ずんだもん: そうなのだ。間違えた問題は、公式ドキュメントで裏付けを取って、ガイドの該当分野を読み直すのだ。
ずんだもん: それと、外部の問題集は非公式なのだ。解説の誤りや古い仕様に、注意するのだ。
めたん: 絶対に使ってはいけないものは？
ずんだもん: 実際の試験問題を流出させた、ダンプ系のサイトなのだ。受験規約違反なのだ。

ずんだもん: 合格の取り消しや、受験禁止のリスクがあるのだ。だから、絶対に使わないのだ。
